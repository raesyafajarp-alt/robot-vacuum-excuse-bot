A program that writes one original one-line excuse a robot vacuum gives for missing a spot, entered in make.fun's "The Robot Vacuum's Best Excuse".

## The entry

> I didn't miss that spot — the dust bunny under the sofa pays rent, so I respect a tenant's rights.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (one line, no trailing newline). Running it twice produces byte-identical output.
